# 📊 Finance Performance Analysis

## Overview

Finance Performance Analysis is an interactive Power BI dashboard designed to analyze revenue, profit, sales, discounts, and product performance. It provides business insights through dynamic visualizations and KPI cards.

---

## Dashboard Preview

![Dashboard](Images/Dashboard.png)
---

## Features

- Executive KPI Dashboard
- Monthly Revenue Trend
- Revenue vs Profit Analysis
- Product Performance Analysis
- Sales Distribution
- Interactive Product Filters
- Monthly Sales Breakdown
